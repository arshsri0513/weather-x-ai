# 🌩️ WEATHER-X AI

> **AI-Driven Spatio-Temporal Tracking of Extreme Weather Anomalies in Medium-Range Forecasts.**

![Weather-X AI Banner](https://img.shields.io/badge/Status-Active_Tracking-emerald?style=for-the-badge) ![Version](https://img.shields.io/badge/Version-1.0.0-blue?style=for-the-badge)

Weather-X AI is a high-tech, real-time command center built for tracking global climate anomalies, extreme weather events, and critical environmental threats. Designed with a premium "dark scientific aesthetic", the platform acts as a simulated intelligence dashboard powered by AI.

🌐 **Live Demo:** [weather-x-ai.vercel.app](https://weather-x-ai.vercel.app)

---

## ✨ Features

- 🌍 **Interactive Global Anomaly Map:** Real-time geospatial mapping of temperature fields, precipitation radars, and wind vectors using Leaflet.
- 🎙️ **Multi-Lingual AI Voice Engine:** Built-in Text-To-Speech (TTS) integration that audibly reports system status in native English and Hindi.
- 📡 **Live Telemetry Dashboard:** A scrolling ticker displaying real-time node latency, threat levels, and satellite uplink status.
- 🔄 **Dynamic Forecast Scrubber:** Synchronized time-step timeline allowing users to cycle through T+ 7, 14, and 21-day predictive horizons.
- ⚡ **AI Threat Feeds:** Simulated live-scrolling intercept feeds detecting regional anomalies (e.g., Cyclones, Heatwaves) prioritizing regions in India and worldwide.
- 🔐 **SaaS Authentication UI:** A sleek, fully animated login/signup terminal with mock social OAuth integrations (Google & GitHub).

## 🚀 Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide-React](https://lucide.dev/)
- **Maps:** [React-Leaflet](https://react-leaflet.js.org/)
- **Deployment:** [Vercel](https://vercel.com/)
